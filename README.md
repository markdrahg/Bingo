# Bingo Scholarship: Scam Awareness Demo

Site URL: https://markdrahg.github.io/Bingo/

A mock scholarship website built for cybersecurity awareness training.
"Bingo Scholarship" is fictional and not a real organisation.

The page imitates common scholarship scam tactics (fake urgency, guaranteed
awards, upfront "processing fees", requests for PINs and ID numbers) so
students can learn to recognise them.

- Click "Show red flags" to see each warning sign explained
- The form does not send or store any data
- Built with plain HTML and CSS, with a little JavaScript

For educational use only.
